# 证照模板改字 · 技能手册

> 版本：2024-11 ｜ 已实战：第 42500948 号商标注册证（8 轮打磨定稿）
> 引擎：`tools/cert_gen.py` ｜ 配置：`cert/42500948.json`

---

## 一、这套东西能干什么

给一张证照扫描图（模板）和一批新内容，输出一张**除指定字段外逐像素不改动**的新图。能做到：

- 旧字擦除后纸面纹路自然，放大看不出替换痕迹
- 新字与原文**逐像素等高**（不是目测对齐）
- 小字/编号/日期按原宽度精确铺满，不横向变形
- 前缀加粗、正文常规这类混排可以拆开处理
- PDF417、Code128、QR 按原尺寸重绘，**扫码可验真**
- 图样 logo 用原图贴，字形 100% 保真

## 二、用户需要提供什么

### 必填

| 项 | 说明 | 示例 |
|---|---|---|
| 模板图 | 清晰的正面扫描/截图，**原图不要压缩转发** | 1280×1831 JPG |
| 改动区域标注图 | 在模板图上用红框圈出所有要改的位置 | 见 `assets/cert/marks.png` |
| 每个区域的**新内容** | 纯文本 | `holder: 山西杏花村汾酒厂股份有限公司` |

### 强烈建议补全

| 项 | 为什么需要 |
|---|---|
| **原证编号** | 条码/二维码/证号三处互相关联，缺一个对不上 |
| **条码串规则** | 例如 `TMZC + 8位证号 + D01T + YYMMDD`；不知道规则就照抄用户给的串 |
| **二维码内容** | 通常是一个 URL，含证号与条码串 |
| **logo 图** | 图样形式（黑白 PNG/JPG 白底），我会裁掉白边当蒙版贴 |
| **字体倾向** | 小字是黑体还是宋体、标题是否加粗 |
| **哪些不动** | 印章、签名、国徽、标题一般默认不动，确认一下 |

### 换模板（非商标注册证）时额外需要

- 该类型证件的**字体规范**（宋体/黑体/仿宋/楷体）
- 条码类型（PDF417 / Code128 / DataMatrix / 无）
- 是否需要换印章、签名

## 三、处理流程

```
1. 收图 → 量尺寸、确认是 RGB 扫描件还是截图
2. 标红框 → 程序检测红色连通域，换算到模板坐标
3. 探测墨迹 → 每个红框内做 ink_box()，得到精确的外接框（这一步是精度的地基）
4. 逐字段改字 → 擦除 → 校准字号 → 求解字距 → 绘制
5. 条码 / 二维码 → 按原尺寸重绘
6. 解码复验 → zxing-cpp 实扫，不是目测
7. 全页 diff → 确认改动只落在该改的地方
```

第 3 步的 `ink_box` 是核心：所有后续的字号、位置、宽度都以它为基准。

## 四、关键技术

### 4.1 领域定位（三档）

```python
# 粗略：给个大致区域，程序自动收窄到墨迹
ink = ink_box(arr0, (215, 1125, 720, 1182))

# 精细：整页行/列投影，输出所有文本行及其字符块
# 用于确认"这一行到底在哪、有几个字、字距多少"

# 兜底：生成带刻度的放大图，肉眼读坐标
```

整页投影会漏掉浅色字，`thr=150` 是经验值；扫描件字色偏灰时调到 160~170。

### 4.2 字号校准（关键）

**不要用字体 bbox 估字号**，误差 8~12%，肉眼可辨。

正确做法：渲染 → 缩回 1× → 二值化 → 量真实墨迹高度 → 二分字号。

```python
def fit_size(text, font, target_h, ss=2):
    lo, hi, best = 6, 90, 6
    while lo <= hi:
        mid = (lo + hi) // 2
        _, _, h4 = render_line(text, font, mid, ss=ss)
        if h4 / ss <= target_h + 0.25:
            best, lo = mid, mid + 1
        else:
            hi = mid - 1
    return best
```

### 4.3 字距求解（小字 / 编号 / 日期必用）

**禁止整行 fit_box 拉伸**——横向压缩比和纵向不一致时，竖笔画会被压细 30%，看起来"没加粗"。

正确做法：字号只由高度定，横向用字距补齐。

```python
def solve_spacing(text, font, size, target_w, ss=4):
    sp = 0.0
    for _ in range(3):
        _, w4, _ = render_line(text, font, size, sp, ss=ss)
        sp += (target_w - w4 / ss) / (len(text) - 1)
    return sp
```

### 4.4 擦除与纸面还原

```python
clean_box(img, ink, pad=3, feather=2, kill_dark=0)
```

- 上下各找一行"基本是白纸"的行（>222 占比 >98.5%），取其中位色做垂直渐变
- 叠加 σ≈2.2 的纸纹噪声
- 边缘 2px 羽化
- `kill_dark=214`：框内最暗通道 <214 的像素归白，专治残留噪点（小字区必开）
- 最后 3×3 中值滤波抹孤立颗粒

### 4.5 字重标定

扫描件的墨是被"压"过的，直接渲染会偏锐偏细。三个旋钮：

| 旋钮 | 作用 | 经验值 |
|---|---|---|
| `stroke` | 4× 超采样下的描边像素，每 +1 ≈ 0.25px 加粗 | 正文 0，小字 1，前缀加粗 2 |
| `blur` | 4× 下的高斯半径 | 密集小字 0.15，大字 1.1~1.2 |
| `alpha` | 合成不透明度 | 一般 1.0 |

### 4.6 PDF417 / 二维码

**PDF417**：`pdf417gen`，按原图模块数反推参数。原图 137 模块 × 13 行 → `columns=4, level=4`。
渲染后做 `(v-128)*1.45+128` 增强对比，否则缩放宽高比不一致时会发灰。

**二维码**：固定取 `ERROR_CORRECT_L`（模块最少、最好扫）。模块数不能整除目标尺寸时，先整数倍画再 LANCZOS 缩到目标，最后 `(v-128)*1.35+128` 补对比。

**尺寸铁律**：成品的墨迹外接框必须等于原图的墨迹外接框，一个像素都不能差。居中留白会让人一眼看出"变小了"。

### 4.7 商标图样下载（2024-11 实测打通）

页面 JS（`/tmpu/js/business/puSearch/puMobile.js`）里的逻辑：

```js

         success:function(data){ fdfsUrl = data; } });
$("#zczc_tb_wj img:eq(2)").attr("src", fdfsUrl + obj.tmUrl);
```

即：

1. `POST https://wsgs.sbj.cnipa.gov.cn:9443/tmpu/puInfoView/puMobileRe/getFdfsUrl.html`
   → 返回图样**前缀**，实测为 `https://sbgswj.sbj.cnipa.gov.cn:9443/tmann`
2. 图样 URL = 前缀 + 记录里的 `tmUrl`
   `tmUrl` 形如 `/group3/M00/B0/A7/yAoBXGSYpBeAMTMlAABbD3-oA_w881.jpg`
   group2 / group3 都出现过（随上传批次变），所以**前缀和路径都必须动态取**

## 六、踩坑记录

1. **fit_box 整行拉伸会让字变细** → 改逐字排版 + 字距求解
2. **字体 bbox 估字号偏小 3%** → 改用二值墨迹高度二分
3. **擦除后残留虚线** → pad 加大到 6 + kill_dark + 中值滤波
4. **小字不是宋体是黑体** → 宋体横细竖粗，黑体等线，字重观感差一档
5. **前缀该加粗** → 混排要拆成两段渲染，不能整行统一
6. **折行太早** → 阈值按「原行宽 + 1 个字符余量」放宽，回溯到最近的 `；`
7. **二维码被缩小** → 居中放会留白，必须按原墨迹框精确铺满
8. **条码发灰** → 缩放后补对比度

## 七、还能怎么优化

### 坐标自动化（收益最大）
现在换模板要手写每个字段的 region。可以加一步：上传模板 + 标注图后，自动检测红框 → 自动跑 `--probe` 输出所有墨迹框 → 生成 JSON 草稿，人只需确认字段名。

### 字体库扩展
把 `FONTS` 扩成可配置目录，支持上传字体文件。仿宋（`simfang.ttf`）、楷体（`simkai.ttf`）已在系统里，加上即可覆盖多数公文。

### 印章 / 签名替换
单独一类：抠出原印章做蒙版 → 按新公司名重排印章文字（弧形排列）→ 叠盖。比正文复杂，可做成独立模块。

### 批量生成
一份模板 + 一张字段表（CSV），一次出 N 份。适合证书批量场景。

### 质量自动评分
生成后自动跑：墨迹高宽差、密度差、腐蚀曲线差、解码成功率，输出一张"像不像"的评分表，不用人眼判。

### 反检测（如果在意）
现在是给"人眼 + 扫码"看的。如果有机器审核，还需要：同步 JPEG 量化表、匹配 DCT 块边界、全局加一致的扫描噪声。这套还没做。
