## A. 商标注册证（复制这段填）

```
注册证号    :
条码串      :   （PDF417 内容，形如 B1021TMZC00000042500948ZCZC0100014）
条码下小字  :   （形如 *TMZC42500948D01T200928*）
二维码内容  :   （URL 或与条码同串）

logo 图样   :   （发图片；单行英文 / 中英双语分别说明）
国际分类    :   （如 第 33 类）
商品项目    :   （照抄分类表原文，用；分隔，几项都行）
注册人      :
注册人地址  :
注册日期    :   YYYY年MM月DD日
有效期至    :   YYYY年MM月DD日
```

### 三个联动项（最容易对不上）

| 项 | 关系 |
|---|---|
| PDF417 串 | `B1021` + `TMZC` + `000000` + **8 位证号** + `ZCZC` + **4 位序号** |
| 小字 | `*TMZC` + **8 位证号** + `D01T` + **YYMMDD**（申请/注册日）* |
| 二维码 URL | `...?regNum=` + **8 位证号** + `&&barCode=` + 完整 PDF417 串 |

\* 小字里的日期不一定等于注册日期，以实际证书为准，拿不准就照抄我给的原串改数字。

## C. 我会回复你什么

1. **字段定位表** —— 每个区域的精确像素坐标，供你核对
2. **成品图** —— 默认原尺寸 JPG q90
3. **差异图** —— 只显示改动区域，确认没误伤
4. **解码结果** —— 条码/二维码实扫出来的内容
5. **指标表** —— 各字段的字高、字宽、墨量密度与原图的对比

---

## D. 提高成品质量的几个习惯

- **传原图**，不要用微信/QQ 转发压缩过的（压缩会破坏 JPEG 量化表，改过的区域一眼能看出来）
- 标注图上的红框**贴着字画**，别留太多空白
- 新内容如果是全角标点就照写全角，别混用
- 证件上有「截止」「以下空白」这类固定后缀，记得一并给全
- 有官方 PDF 或高清图优先给，扫描件次之，手机翻拍最差
