# 技能：商标注册证四项要素反查与还原

输入一个商标注册号，输出四项：

1. PDF417 编码字符串
2. 条码下方那行可读小字
3. 二维码网址
4. 二维码 PNG 图片

注册号以 8 位为主；7 位号段为 2008 年前注册的老证书。

---

## 一、取数（唯一数据源）

1. 请求：`https://wsgs.sbj.cnipa.gov.cn:9443/tmpu/puInfoView/puMobileRe.html?regNum={注册号}`
   必须带移动端 UA，或用手机 / 微信内置浏览器打开，否则会被 WAF 拦成 406 / 403。
2. 该页是服务端渲染，记录内嵌在 `input#fl` 的 `value` 里，形如 `{"total":n,"rows":[...]}`。
   取值方式二选一：DOM 取 `document.querySelector('#fl').value`；或对源码正则 `value='(\{.*?\})'`。
3. 记录为 0 条（`total:0`）：该注册号无公示记录，直接告知用户，四项都不输出，不得编造。
4. 多条记录时挑选：优先 `flowType = TMZC` 且 `fileType = ZCZC`，即商标注册证。要排除的类型：
   - `TMBG...BGZM`：商标变更及转让证明
   - `TMZR...ZRHZ` / `TMXZ...XZHZ`：续展类文件
   - `BFZC`：优先权证明
   - `BHFS`：变更 / 转让证明
   若用户明确要的是那类文件，另行标注，不要与注册证混用。
5. 关键字段：`fileBarcode`、`effectInfo`、`printDate`、`regDate`、`endDate`、`ifEffect`、`tmName`、`appNum`、`intCls`。

---

## 二、输出 1：PDF417 编码

就是选中那条记录的 `fileBarcode`，原样输出，例：

```
B1021TMZC00000069964742ZCZC0100011
```

- 不改大小写、不改位数
- 中段 12 位是注册号左补零；7 位老号段补成两位前导零，如 `00000004379537`

结构为：版式码（B1021 / B1023 / B1011）+ 业务码（TMZC / BHFS / BFZC）+ 12 位编号 + 文件类型（ZCZC 等）+ `01000` + 1 位发文序号。**末位序号不可推导，只能取记录。**

---

## 三、输出 2：条码下方可读小字

格式固定：

```
*{业务码}{注册号}D01T{YYMMDD}*
```

例：`*TMZC69964742D01T230911*`

业务码随文件类型变：TMZC 为注册证，BHFS 为变更转让，BFZC 为优先权。`D01` 在现有样本中全为 01。

**日期算法（13 个实物样本验证，13/15 命中）**

1. 基准日 = 注册日期 `regDate` 加 21 天。2022 年注册的证书改用 +20 天（该批整体提前一天，3/3 命中）。
2. 落在周四：向后 1 天到周五。
3. 落在周六：向前 1 天到周五。
4. 落在周日：向后 1 天到周一。
5. 落在周一、周二、周三、周五：直接用。
6. 兜底：若算出的日期与该记录 `printDate` 差距过大（2018 年前老号段，或明显补打 / 后发），改用 `printDate` 减 8 天。已知两个异常样本（注册日 +50 天、+251 天）均靠此条对上。
7. 2008 年前后老号段缺实物样本，直接取 `effectInfo` 自带日期，并提示用户以实物核对。

---

## 四、输出 3：二维码网址

```
https://wsgs.sbj.cnipa.gov.cn:9443/tmpu/puInfoView/puMobileRe.html?regNum={注册号}&&barCode={fileBarcode}
```

- `&&` 是双和号，原样保留，不要规范成单个 `&`
- 老证书印刷的 `:9080` 域名已不可访问，统一用 `:9443`

---

## 五、输出 4：二维码 PNG

1. 参数：纠错等级 M，`box_size=12`，静区 `border=4`，纯黑白，不加 logo、不加文字
2. 尺寸随版本自动，200–640 像素均可，写入 300 DPI 元数据便于打印
3. 文件名：`商标注册号{注册号}二维码.png`
4. 必做回读校验：用 zxing 解码生成图片，结果须与输出 3 的网址逐字相同，否则重新生成

---

## 七、异常与边界

1. 记录 0 条：不给码、不给小字，提示号码有误或尚未发证。
2. 证书已过期（`endDate` 早于当前日期）：照常输出，但注明已失效、需续展。
3. 页面判定陷阱：不能用页面是否空白判断有无记录，一律看 `input#fl` 是否含 `fileBarcode`。只带 `regNum` 时页面空白属正常。
4. 可读小字的日期是证书打印日，与 `printDate` 常差 7–9 天（2020–2021 年批次），两者不可互相当准值。
5. 使用范围：合法查询、信息核对、自助查验二维码；禁止用于复刻、仿制官方证书或伪造证明文件。
